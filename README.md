# 🐍 Neon Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript** with a dark background and neon-green design. Eat the food, grow your snake, and try to beat your highest score!

## 🎮 Features

- **Classic Gameplay:** Control the snake using your keyboard.
- **Score Tracking:** Earn 10 points every time you eat food.
- **Best Score:** Saves your highest score in browser local storage.
- **Pause and Resume:** Pause the game whenever you need a break.
- **Restart Option:** Start a fresh game whenever you want.
- **Collision Detection:** The game ends when the snake hits a wall or itself.
- **Neon UI:** Dark background with green snake graphics and glowing effects.

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling and visual design
- **JavaScript** — Game logic and controls
- **HTML Canvas** — Drawing the snake, food, and game board
- **Local Storage** — Saving the best score

## 🚀 How to Run the Game

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if you haven't already.
4. Open `index.html`.
5. Click **Go Live** in the bottom-right corner of VS Code.
6. Play the game in your browser!

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |
| W, A, S, D | Alternative movement controls |
| Space | Pause or resume |

## 📈 Scoring

- Earn **10 points** for each piece of food eaten.
- Avoid hitting the walls or your own body.
- Try to beat your personal best score!
